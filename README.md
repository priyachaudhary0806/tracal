# TRACAL 🏡
### AI-Powered Smart Homestay Booking & Travel Platform

TRACAL is an AI-powered homestay booking platform designed to make travel planning smarter, safer, and more personalized.

It combines intelligent travel assistance, personalized recommendations, property management, and role-based dashboards into one platform.

## ✨ Key Features

### 🤖 AI-Powered Features
- Smart Trip Budget Planner
- AI Travel Personality Analysis
- AI Local Explorer
- TrustScore – Property Trust Evaluation
- Review Intelligence – Smart Review Analysis
- Reality Check – Property Information Insights
- AI Host Insights
- Admin AI Monitoring

### 👤 Guest Portal
- Explore and search homestays.
- View property details and availability.
- Book homestays.
- Manage reservations and favorites.
- Get personalized travel recommendations.
- Access AI travel assistance.

### 🏠 Host Portal
- Manage property listings.
- Manage bookings and availability.
- Access AI-powered host insights.
- Submit host verification requests.

### 🛡️ Admin Portal
- Manage users and properties.
- Review host verification requests.
- Monitor bookings and platform activity.
- Access analytics and AI monitoring.
- Manage platform operations.

## 🛠️ Tech Stack

**Frontend**
- Next.js
- React.js
- TypeScript
- Tailwind CSS

**Backend**
- Python
- FastAPI
- REST APIs

**Database**
- MongoDB

**AI Integration**
- Google Gemini API

**Other Integrations**
- Razorpay Payment Integration
- OpenStreetMap
- Nominatim
- Overpass API
- JWT Authentication

## 🏗️ Project Architecture

TRACAL follows a frontend-backend architecture:

- Frontend: Next.js application
- Backend: FastAPI REST API
- Database: MongoDB
- AI Services: Gemini-powered intelligence features

## 🚀 Project Vision

Our vision is to simplify travel experiences by combining homestay discovery, intelligent planning, trustworthy property information, and personalized AI assistance.
